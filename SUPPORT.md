# Support

Use GitHub Issues for reproducible bugs and focused feature requests. Include the SpecBridge version, operating system, Node.js version, the failing command or conversational flow, and a minimal synthetic reproduction where possible.

Do not attach confidential repositories, secrets, or unredacted Spec Packs to public issues.

SpecBridge 2.x supports its design-and-specification workflow. The discontinued 1.x execution runtime, persisted Jobs, implementation workers, and related compatibility surfaces are not supported.
