# SpecBridge status

Use `workspace_detect` for a workspace summary, `design_read` for a named session, and `spec_list` or `spec_read` for compiled artifacts. State the session lifecycle status, current stage, next bounded action, unanswered material product decisions, unresolved research, evaluation readiness, and Spec Pack revision.

Do not describe implementation workers, attempts, jobs, worktrees, or coding progress; those are outside SpecBridge 2.0.
